Acessar o instagram

Utilizamos o atributo chamado de target. Esse atributo serve para indicar onde o link configurado no href será aberto.

Algumas opções do target:

  • _self : abre na mesma aba. É a configuração padrão.
  • _blank : abre o link em uma nova aba/janela.
  • _parent : abre no contexto pai, usado com iframe.
  • _top : abre no contexto mais externo também com iframe.
